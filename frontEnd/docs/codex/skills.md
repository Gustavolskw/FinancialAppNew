## Ordem Recomendada

1. Leia `AGENTS.md`.
2. Leia `.codex/README.md` na raiz do projeto e `frontEnd/.codex`.
3. Leia `docs/codex/project-context.md`, `agent-playbook.md`, este arquivo e `review-notes.md`.
4. Identifique se a tarefa toca rotas/UI, API ou Docker.
5. Leia a Skill correspondente.
6. Edite e rode as verificações proporcionais.
